# Интерфейс

Одностраничное приложение без маршрутизатора URL. Состояние экрана — `page` в `frontend/src/App.tsx`. Сборка: React 19, Vite, Bun. Запросы — `frontend/src/api.ts`: cookie-сессия, заголовок CSRF на мутациях, разбор `DomainError` в русский текст через `apiErrorMessages.ts`.

Навигация слева:

| id | Экран | Файл |
| --- | --- | --- |
| `overview` | Обзор | `pages/Overview.tsx` |
| `clusters` | Кластеры | `pages/Clusters.tsx` |
| `runs` | Проверки | `pages/Runs.tsx` |
| `findings` | Находки | `pages/Findings.tsx` |
| `imports` | Импорт отчётов | `pages/Imports.tsx` |
| `modes` | Возможности | `ModesPage` в `Overview.tsx` |
| `audit` | Журнал действий | только `administrator`, компонент в `App.tsx` |
| `settings` | Настройки | `pages/Settings.tsx` |

Наблюдатель видит плашку, что запуск и импорт недоступны. Сервер всё равно проверяет роль.

Тема светлая или тёмная хранится в браузере. Время на экране — локальная зона браузера, в данных API — ISO.

## Кластеры

Шапка страницы: «Обновить» и «Подключить кластер» для администратора.

Панель «Мои черновики» — только администратор. «Продолжить» открывает мастер с тем же id. Закрытие мастера черновик не удаляет. Отдельная кнопка подтверждает удаление черновика.

Панель «Подключения». В шапке, над таблицей, у администратора кнопки «Добавить», «Изменить», «Удалить». «Изменить» и «Удалить» включаются после галочки: правка — ровно один кластер, удаление — один или несколько. «Изменить» меняет название и окружение. «Удалить» открывает `AdminConfirmation`: пароль, затем `DELETE`. Текст предупреждает, что Kubernetes не меняется.

Под шапкой, если роль может сканировать и есть готовые кластеры, вторая полоса: «Запустить проверку», «Сканеры», «Расширенные», «Оператор», «Наблюдение», «Уязвимости». Проверка шлёт `POST /api/runs` с namespace самого подключения. Остальные, кроме уязвимостей, шлют `protected-action` с `confirm: true`. «Наблюдение» — это `continuous`. «Уязвимости» открывают экран находок этого кластера и доступны для одной галочки.

Строка таблицы открывает карточку подключения: область, preflight, смена namespace (администратор, с паролем), личный отзыв, административный отзыв всех.

Мастер `ConnectionWizard.tsx`: файл kubeconfig, контекст, имя, окружение, режим хранения, обнаружение namespace, пустой начальный выбор, preflight, финализация. Дубликат конечной точки показывает отдельный шаг, а не тихое второе подключение.

## Остальные экраны

Обзор: счётчики, последние запуски, состояние обработчиков, ссылка на возможности. Заголовок возможностей: «Состояние функций в версии {version}». Карточки делятся на «Доступно» (`available` или `implemented`) и «Не реализовано».

Проверки: список, карточка, отмена, отчёт. Покрытие показывается отдельно от находок.

Находки: фильтр, разбор по роли, кнопка исправления только если роль может сканировать, вид — контроллер, правило — одно из четырёх builtin. Запрос — `protected-action` `remediate` с `finding_id`.

Импорт: Trivy, kube-bench и Kubescape идут в `POST /api/imports`. Falco и Tetragon — в `POST /api/runtime-imports`.

Настройки: редактор политики исходящих подключений. Сначала просмотр замены, затем пароль, затем `PUT` с `expected_revision`. Провайдеров единого входа на экране нет.

Общие куски: `ui.tsx` (панель, модалка, бейдж), `NamespacePicker.tsx`, `NamespaceAccess.tsx`, `ScopeEditor.tsx`, `RunLaunch.tsx`, `CredentialRecovery.tsx`, `AdminConfirmation.tsx`. Выбор namespace не отмечает новые имена сам и не даёт сохранить больше ста.

Вёрстка не должна давать горизонтальный скролл страницы на широком и на узком (около 390px) окне. Таблицы скроллятся внутри `.table-scroll`. Длинные имена переносятся.
